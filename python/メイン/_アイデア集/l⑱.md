# **AI × Python 開発アイデア集 (Part 18\)**

## **～日常の科学・バリアフリー・収集・音響：ぬか床からバイオリンまで～**

既存のPart 1～17には含まれていない、**食品や環境の科学的分析**、**車椅子や自転車向けの移動支援**、**音楽室や楽器の音響解析**、**コレクター向けの自動鑑定** など、より生活に密着したニッチなPython開発アイデア20選です。

### **🔬 日常の科学・食品テック (Daily Science & Food)**

#### **1\. ぬか床・発酵食品「カビ判定」モニター**

* **概要:** ぬか床や自家製チーズの表面写真を解析し、「産膜酵母（白・無害）」か「青カビ・赤カビ（有害）」かを色相とテクスチャで識別して警告します。  
* **技術:** Color Segmentation (HSV), Texture Classification  
* **ポイント:** 失敗しやすい自家製発酵食品の管理を、視覚センサーで安全に行います。

#### **2\. 鮮魚「目の濁り」鮮度判定AI**

* **概要:** スーパーや市場で魚の顔（目とエラ）を撮影すると、目の透明度やエラの赤みを解析し、「水揚げから推定〇日」や「刺身で食べられるか」を判定します。  
* **技術:** Region of Interest (ROI) extraction, Regression Model  
* **ポイント:** プロの目利き（仲買人）の技術を画像認識で再現します。

#### **3\. 分子ガストロノミー「意外な組み合わせ」レシピ**

* **概要:** 食材に含まれる「香気成分（フレーバー化合物）」のデータベースを用い、成分が共通する意外な食材同士（例：チョコとブルーチーズ、醤油とバニラ）のペアリングを提案します。  
* **技術:** Network Analysis (Ingredient Graph), Pandas  
* **ポイント:** 経験や勘ではなく、化学データに基づいた新しい味の探求を支援します。

#### **4\. 自作「花粉」カウンター (DIY Microscope)**

* **概要:** スマホ用顕微鏡レンズで採取したスライドガラスを撮影し、画像処理でスギ花粉やヒノキ花粉の粒子数を自動カウントして「今日の飛散量」をログ化します。  
* **技術:** Blob Detection (OpenCV), Shape Classification  
* **ポイント:** ニュースの飛散予報ではなく、自分の家の周りのリアルな花粉量を計測します。

### **♿ バリアフリー & モビリティ (Accessibility & Mobility)**

#### **5\. 車椅子用「段差・勾配」検知マッパー**

* **概要:** アクションカメラで歩道を撮影しながら移動し、車椅子の走行を妨げる「2cm以上の段差」や「急な勾配」を検出して、バリアフリー地図を自動作成します。  
* **技術:** Depth Estimation (Stereo Vision or MiDaS), IMU sensor data  
* **ポイント:** 健常者には見えない「見えない壁」を可視化し、移動ルートを最適化します。

#### **6\. EV（電気自動車）「充電計画」最適化**

* **概要:** 走行ログ（標高差、気温、エアコン使用率）を分析し、バッテリー消費を予測。長距離ドライブの際、「どこで・何分充電するのが最短か」を算出します。  
* **技術:** Physics-based Modeling, Optimization Algorithm  
* **ポイント:** メーカー純正ナビよりも詳細な条件設定で「電欠」の不安を解消します。

#### **7\. 駐輪場「空きスペース」発見カメラ**

* **概要:** 混沌とした駐輪場のカメラ映像から、自転車と自転車の隙間（デッドスペース）を認識し、「あそこに1台停められます」とスマホにAR表示します。  
* **技術:** Object Detection (YOLO), Free Space Detection  
* **ポイント:** 満車に見えても実は停められる場所を、画像処理で瞬時に見つけます。

#### **8\. 道路標識「老朽化」インベントリ作成**

* **概要:** ドライブレコーダーの映像から「一時停止」や「速度制限」の標識を検出し、その位置情報とともに「傾き」「退色（色あせ）」具合を記録して自治体に報告するデータを作ります。  
* **技術:** Object Detection, Color Histogram Analysis  
* **ポイント:** Part 7の道路の穴検知に加え、インフラ設備の維持管理を自動化します。

### **🎻 音響・楽器・トレーニング (Acoustics & Training)**

#### **9\. 部屋の「響き（残響時間）」測定器**

* **概要:** 部屋で手を叩く（クラップ）音をマイクで拾い、音が60dB減衰するまでの時間（RT60）を計算。「吸音材をもう少し貼った方がいいです」とアドバイスします。  
* **技術:** Signal Processing (Energy Decay Curve), SciPy  
* **ポイント:** DTMやオーディオ鑑賞のためのルームチューニングを数値化します。

#### **10\. アナログレコード「プチプチ音」除去 (De-Clicker)**

* **概要:** デジタル化したレコード音源の波形から、特有の「プチッ（スクラッチノイズ）」という急峻なピークを検出し、その部分だけを前後から補間して修復します。  
* **技術:** Wavelet Transform or Statistical Outlier Detection  
* **ポイント:** 思い出のレコード音源を、Pythonだけでクリアな音質に蘇らせます。

#### **11\. バイオリン「弓の角度」矯正コーチ**

* **概要:** 演奏中の右手の動きを真上からカメラで撮影し、弓が弦に対して「直角」に動いているかを判定。曲がっているとリアルタイムで警告します。  
* **技術:** Line Detection (Hough), Angle Measurement  
* **ポイント:** 初心者が最も苦戦する「ボーイング（運弓）」の基礎練習を支援します。

#### **12\. 声の「性別・年齢」推定 & 変換可視化**

* **概要:** マイクに入力された声のフォルマント周波数や基本周波数を解析し、「30代男性の声」などの推定結果を表示。ボイストレーニングの目標値とのズレを可視化します。  
* **技術:** Praat (Python wrapper), Voice Analysis  
* **ポイント:** 「理想の声」に近づくための客観的な指標を提供します。

### **🧐 鑑定・収集・ホビー (Collection & Hobby)**

#### **13\. トレカ「初期傷・センタリング」グレーディング**

* **概要:** トレーディングカードの高解像度スキャン画像を解析し、表面の微細な傷（白欠け）や、印刷のズレ（センタリング）をピクセル単位で測定してランク付けします。  
* **技術:** Edge Detection, Pixel Analysis, Template Matching  
* **ポイント:** 高騰するトレカ市場に向けた、個人的な品質鑑定（PSA鑑定の前段階）ツールです。

#### **14\. 切手「国・額面」自動仕分け機**

* **概要:** バラバラの切手の山をスキャンすると、画像検索技術で「どこの国の何年の切手か」を特定し、カタログ価格とともにリスト化します。  
* **技術:** Image Retrieval (Feature Matching), Web Scraping (Stamp Catalog)  
* **ポイント:** 遺品整理などで大量に出てくる古切手の価値を一瞬で判別します。

#### **15\. 折り紙「次の一手」ARガイド**

* **概要:** 折りかけの折り紙をカメラに映すと、現在の工程を認識し、「次はここを谷折り」という点線と矢印を紙の上に直接AR投影します。  
* **技術:** Contour Analysis, Step-by-Step State Estimation  
* **ポイント:** 動画を見ても分からない「複雑な折り紙」の挫折を防ぎます。

#### **16\. 化石・鉱物「テクスチャ」識別図鑑**

* **概要:** 河原で拾った石の断面を接写すると、表面のテクスチャから「ただの石」か「植物の化石」か「チャート（火打石）」かを確率で判定します。  
* **技術:** Texture Classification (CNN), Macro Image Analysis  
* **ポイント:** 夏休みの自由研究や、大人の鉱物採集をサポートします。

#### **17\. 習字「書き順」判定AI**

* **概要:** 文字を書いている動画を解析し、筆の動きをトラッキング。「『右』という字の書き順が違います（ノ→一になっています）」と指摘します。  
* **技術:** Motion Tracking, Stroke Order Database  
* **ポイント:** 完成した文字を見るだけでは分からない「プロセス」の間違いを正します。

#### **18\. そろばん「盤面」読み取りリーダー**

* **概要:** そろばんの珠（たま）の位置をカメラで認識し、現在の数値をデジタル表示します。計算中の動画から、指使いのスピードや正確性も分析可能です。  
* **技術:** Object Detection (Bead position), Digit Recognition Logic  
* **ポイント:** 珠算の検定試験練習や、計算結果の即時答え合わせに使えます。

#### **19\. 手書きノート → 暗記カード生成 (Flashcard Maker)**

* **概要:** 授業ノートの写真を撮ると、LLMが重要な用語と定義を抽出し、Ankiなどのアプリで使える形式（CSV）の単語帳データを自動生成します。  
* **技術:** OCR, LLM (Question Generation), Export Formatting  
* **ポイント:** Part 6の検索ツールとは異なり、「テスト勉強」に特化した学習支援です。

#### **20\. 家紋「ルーツ」検索カメラ**

* **概要:** 墓石や着物の「家紋」を撮影すると、その名称（丸に剣片喰など）を特定し、その家紋の由来や、使用していた戦国武将などの歴史データを表示します。  
* **技術:** Fine-grained Image Classification, Historical Database  
* **ポイント:** 日本独自の紋章文化を解き明かす、フィールドワーク用アプリです。
